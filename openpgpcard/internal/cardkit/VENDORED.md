# Vendored smart-card stack

This directory holds the vendored fork of the cunicu smart-card stack:

- `go-openpgp-card` (OpenPGP card spec 3.4.1 client)
- `go-iso7816` (ISO 7816 APDU/TLV layer)

Vendored from https://codeberg.org/cunicu (the GitHub org was deleted in
Dec 2025). The openpgpcard implementation plan, Task 1, records the exact
commit to vendor in VENDORED.md.
